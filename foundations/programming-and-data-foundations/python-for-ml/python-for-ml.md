# Python for ML
> Python is the lingua franca of machine learning — every major framework (scikit-learn, PyTorch,
> TensorFlow) speaks it, and its data stack (NumPy, Pandas, Matplotlib) is where the work happens.
> You don't need to be a software engineer; you need the core language plus comfort with the data
> tools. This card gets you the Python foundation; the next three cards cover the data stack.

**Why it matters:** you can't do ML without writing code, and that code is Python. Interviewers
expect fluency with the basics — lists/dicts, comprehensions, functions, slicing, and reading data —
because every take-home and live-coding ML exercise is written in it.

**Start here — suggested path:**

1. **Learn the core language** — work the [official tutorial](https://docs.python.org/3/tutorial/), or watch [Corey Schafer's Python series](https://www.youtube.com/playlist?list=PL-osiE80TeTt2d9bfVyTiXJA-UTHn6WwU). *Variables, control flow, functions, lists and dicts — the foundation.*
2. **Practice interactively** — work through [Kaggle Learn: Python](https://www.kaggle.com/learn/python). *Short, hands-on lessons that stick because you type them.*
3. **Go straight to the ML-relevant bits** — read [A Whirlwind Tour of Python](https://jakevdp.github.io/WhirlwindTourOfPython/), then the NumPy and pandas chapters of the [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/). *The slice of Python you actually use in ML, written for people who want to get to the data.*
4. **Build the right habits** — read [Automate the Boring Stuff (Ch. 1–6)](https://automatetheboringstuff.com/). *Free book; turns syntax into the ability to actually get things done.*
5. **Keep a reference open** — bookmark [the Python docs](https://docs.python.org/3/) and the [standard library reference](https://docs.python.org/3/library/index.html). *Look things up as you go rather than memorizing.*

## Courses (free)
- [Kaggle Learn — Python](https://www.kaggle.com/learn/python) — **Kaggle** — free, interactive; the fastest path to ML-ready Python.
- [Python for Everybody](https://www.py4e.com/) — **Dr. Chuck (U. Michigan)** — free, beloved full course from absolute zero.
- [The Python Tutorial (official)](https://docs.python.org/3/tutorial/) — **Python Software Foundation** — the canonical, always-correct reference course.
- [MIT 6.0001 — Introduction to Computer Science and Programming in Python](https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/) — **MIT OpenCourseWare** — free lectures, problem sets and solutions; the rigorous option if you want computer science alongside the syntax.

## Videos
- [Python Tutorials (full playlist)](https://www.youtube.com/playlist?list=PL-osiE80TeTt2d9bfVyTiXJA-UTHn6WwU) — **Corey Schafer** — the reference series: data structures, comprehensions, functions, decorators, generators, virtual environments — one precise episode per idea.
- [Introduction to Numerical Computing with NumPy](https://www.youtube.com/watch?v=ZB7BZMhfPgk) — **Enthought** — the jump from Python loops to array thinking, which is where ML code actually lives.
- [The spelled-out intro to neural networks and backpropagation: building micrograd](https://www.youtube.com/watch?v=VMj-3S1tku0) — **Andrej Karpathy** — 100 lines of plain Python that build an autodiff engine; the best demonstration of how little language surface ML needs.

## Key Papers
- [The Python Language Reference](https://docs.python.org/3/reference/) — **Python Software Foundation** — the authoritative spec; the closest thing to a "source" for the language.
- [Python for Scientific Computing](https://aip.scitation.org/doi/10.1109/MCSE.2007.58) — **Pérez, Granger & Hunter (2011)** — why Python became the scientific/ML stack.
- [Array Programming with NumPy](https://www.nature.com/articles/s41586-020-2649-2) — **Harris et al. (2020, Nature)** — the foundation the whole Python ML stack is built on.

## Articles / Blogs (free, no paywall)
- [Python for Everybody (free reading)](https://www.py4e.com/lessons) — **Dr. Chuck** — each lesson with notes, code, and exercises, fully open.
