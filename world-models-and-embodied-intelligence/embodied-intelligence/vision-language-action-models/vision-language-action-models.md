# Vision-Language-Action Models
> A **vision-language-action (VLA) model** takes a pretrained vision-language model (VLM) and adds
> one more output modality: **robot actions**. Web-scale semantics come free from the VLM; the robot
> data only has to teach the mapping from "pick up the red block" to joint torques. It is transfer
> learning applied to a body.

**Why it matters:** VLAs are the 2025-26 mainstream of robot learning — π0 and π0.5 from Physical
Intelligence, OpenVLA as the open baseline, Gemini Robotics 1.5 with explicit "think before acting"
reasoning. The interview substance is the **action representation**: discretised action tokens
(RT-2), flow-matching action experts (π0), or a fast/slow split where a reasoning model plans and a
small policy executes at control frequency. Latency is the constraint that decides the design.

**Start here — suggested path:**

1. **See the core trick** — read [RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control](https://arxiv.org/abs/2307.15818) — **Brohan et al., Google DeepMind (2023)**. *Emit actions as text tokens and a web-pretrained VLM becomes a robot policy.*
2. **Get the open baseline** — read [OpenVLA: An Open-Source Vision-Language-Action Model](https://arxiv.org/abs/2406.09246) — **Kim et al. (2024)**. *A 7B model on 970k demonstrations, fine-tunable on a consumer graphics processing unit (GPU) with low-rank adaptation.*
3. **Learn the flow-matching action head** — read [π0: A Vision-Language-Action Flow Model for General Robot Control](https://arxiv.org/abs/2410.24164) — **Physical Intelligence (2024)**. *Continuous, high-frequency action chunks generated by flow matching instead of token decoding.*
4. **See open-world generalisation** — read [π0.5: a VLA Model with Open-World Generalization](https://www.pi.website/blog/pi05) — **Physical Intelligence (2025)**. *Cleaning kitchens it has never seen; the blog explains the hierarchy better than the paper does.*
5. **Add explicit reasoning** — read [Gemini Robotics 1.5 brings AI agents into the physical world](https://deepmind.google/blog/gemini-robotics-15-brings-ai-agents-into-the-physical-world/) — **Google DeepMind (2025)**. *An embodied reasoning model that plans and a VLA that executes, with motion transfer across robot bodies.*

## Key Papers

- [RT-1: Robotics Transformer for Real-World Control at Scale](https://arxiv.org/abs/2212.06817) — **Brohan et al. (2022)** — the tokenised-action transformer that started the line.
- [RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control](https://arxiv.org/abs/2307.15818) — **Brohan et al. (2023)** — co-fine-tuning on web data and robot data; emergent semantic generalisation.
- [Open X-Embodiment: Robotic Learning Datasets and RT-X Models](https://arxiv.org/abs/2310.08864) — **Open X-Embodiment Collaboration (2024)** — the pooled cross-robot dataset that made generalist policies trainable.
- [OpenVLA: An Open-Source Vision-Language-Action Model](https://arxiv.org/abs/2406.09246) — **Kim et al. (2024)** — the reproducible reference model, weights and training code included.
- [π0: A Vision-Language-Action Flow Model for General Robot Control](https://arxiv.org/abs/2410.24164) — **Physical Intelligence (2024)** — flow-matching action generation at 50 Hz.
- [π0.5: a Vision-Language-Action Model with Open-World Generalization](https://arxiv.org/abs/2504.16054) — **Physical Intelligence (2025)** — hierarchical inference: predict a subtask in language, then the actions for it.
- [Gemini Robotics 1.5](https://arxiv.org/abs/2510.03342) — **Google DeepMind (2025)** — multi-embodiment VLA with motion transfer and interleaved reasoning.
