# Scientific and Specialized Deep Learning

> Deep learning where the data is not a grid of pixels or a stream of tokens — graphs, meshes,
> molecules, and partial differential equations. The common thread is that **the structure of the
> problem is built into the architecture** rather than learned from examples. This is the curated
> shortlist of the best free resources for each of those structures.

**Start here:** read [A Gentle Introduction to Graph Neural Networks](https://distill.pub/2021/gnn-intro/) — **Distill** — for the message-passing picture, then [Geometric Deep Learning: Grids, Groups, Graphs, Geodesics, and Gauges](https://arxiv.org/abs/2104.13478) — **Bronstein, Bruna, Cohen & Veličković** — for the symmetry frame that ties all of it together.

## Courses (free)

- [Stanford CS224W: Machine Learning with Graphs](https://web.stanford.edu/class/cs224w/) — **Stanford (Jure Leskovec)** — the reference graph-learning course, free slides and videos.
- [AMMI Geometric Deep Learning Course (2022)](https://www.youtube.com/playlist?list=PLn2-dEmQeTfSLXW8yXP4q_Ii58wFdxb3C) — **Bronstein, Bruna, Cohen & Veličković** — architectures derived from symmetry.
- [Physics Informed Machine Learning](https://www.youtube.com/playlist?list=PLMrJAkhIeNNQ0BaKuBKY43k4xMo6NSbBa) — **Steve Brunton (University of Washington)** — the scientific-machine-learning lecture series.

## Key Papers

- [Semi-Supervised Classification with Graph Convolutional Networks](https://arxiv.org/abs/1609.02907) — **Kipf & Welling (2016)** — the GCN layer.
- [Fourier Neural Operator for Parametric PDEs](https://arxiv.org/abs/2010.08895) — **Li et al. (2020)** — operator learning in the frequency domain.
- [GraphCast](https://arxiv.org/abs/2212.12794) — **Lam et al. (DeepMind, 2022)** — the applied result that put this sub-area on the map.
- [Geometric Deep Learning](https://arxiv.org/abs/2104.13478) — **Bronstein et al. (2021)** — the unifying blueprint.
